# Kombucha PWA

GitHub Pages: Dateien in das Hauptverzeichnis eines öffentlichen Repositorys hochladen. Settings > Pages > Deploy from a branch > main > / (root) > Save. HTTPS-Link öffnen. Android: Chrome-Menü > App installieren / Zum Startbildschirm hinzufügen. iPhone: Safari > Teilen > Zum Home-Bildschirm. Erst online öffnen, damit der Offline-Cache aufgebaut wird. PDF ist auch in index.html eingebettet.
